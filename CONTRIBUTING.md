# How to contribute

1. Fork this repository on GitHub.
2. Create a new branch for your feature or bugfix.
3. Make your changes and commit them with clear messages.
4. Push your branch and open a Pull Request.
5. Please follow PEP8 and keep code/documentation clear.

For major changes, open an issue to discuss what you want to change.
---

# Nasıl katkı sağlanır

1. Bu repoyu GitHub'da fork'layın.
2. Özellik veya hata düzeltmesi için yeni bir branch açın.
3. Değişikliklerinizi yapıp, açıklayıcı commit mesajlarıyla kaydedin.
4. Branch'inizi push'layıp Pull Request açın.
5. Kod ve dokümantasyonda PEP8 ve açıklık kurallarına uyun.

Büyük değişiklikler için önce bir issue açıp tartışma başlatın.
